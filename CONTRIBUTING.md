# Contributing

Thanks for your interest in Rocktier PDF Squeeze!

## Code of Conduct

Be respectful. Be constructive. Keep it minimal.

## How to Contribute

1. Fork the repo
2. Create a branch from `develop`
3. Make your changes (ponytail-first: simplest solution that works)
4. Run `npm run build` and ensure CI passes
5. Submit a PR

## Design Principles

- **Ponytaile-first**: simplest solution that works
- **Fast by default**: no unnecessary abstractions
- **Privacy non-negotiable**: no network, no telemetry
- **Light as air**: keep installer small, RAM low

## Commit Messages

Use conventional commits:
- `feat:` new feature
- `fix:` bug fix
- `refactor:` code change
- `docs:` documentation
- `style:` formatting
- `test:` tests
- `chore:` maintenance
