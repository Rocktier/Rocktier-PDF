# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by email to hello@rocktier.com.

Do not open public issues for security vulnerabilities.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1   | No                 |

## Security Practices

- All processing is local; no data leaves the user's machine
- No telemetry or analytics in production
- Dependencies are audited via Dependabot
- CI runs on all PRs
